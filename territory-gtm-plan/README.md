# Territory GTM & Quota Velocity Plan

A field-tested territory planning framework from a top 2% national performer (Comcast Elite, 120% quota attainment).

## The framework
1. Segment - tier accounts by propensity: install base, whitespace, competitive displacement targets
2. Coverage math - pipeline coverage ratio required (3x for new business), activity levels per tier
3. Quota pacing - monthly/quarterly pacing with catch-up triggers: if pacing < 90% by week 6, shift effort to highest-velocity segment
4. Weekly operating cadence - pipeline review, stuck-deal triage, next-week commit
