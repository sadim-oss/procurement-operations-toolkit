# SOW Red-Flag Checklist

The clause-by-clause contract review framework from 7+ years of vendor SOW review.

## The checklist
| Clause | Red flag | Your check | Redline move |
|---|---|---|---|
| Acceptance criteria | Vague / subjective | Must be objective, measurable, time-bound | Insert "deemed acceptance after 10 business days without written objection" |
| Change management | Verbal scope changes | Written change order required | No written change order = no scope change |
| Payment terms | Calendar-based billing | Tie to milestones | Milestone acceptance triggers payment |
| Liability caps | Uncapped / one-sided | Compare to contract value | Cap at fees paid, mutual |
| Auto-renewal | Silent renewal | Flag renewal date + notice window | Require written notice 60 days out |
| Data ownership | Vendor owns deliverables | Work-for-hire explicit | IP assigns on payment |
| SLAs | No remedies | Credits for misses | Service credits, termination right |
