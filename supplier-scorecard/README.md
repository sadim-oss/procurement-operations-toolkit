# Supplier Scorecard

A weighted supplier evaluation template for defensible sourcing decisions - because the lowest bid is rarely the lowest cost.

## Criteria & weights (adjust per category)
| Criterion | Weight |
|---|---|
| Quality | 20% |
| Total cost of ownership | 20% |
| Delivery / on-time % | 15% |
| Technical capability | 10% |
| Financial stability | 10% |
| Capacity | 10% |
| Risk & compliance | 10% |
| Service & communication | 5% |

Score each 1-5 with evidence notes. Weighted score = sum(score × weight). Document the decision.
