# Negotiation Playbook

How to trade concessions without giving away margin - from someone who protected it for 7 years.

## The framework
- Preparation - know your walk-away, their alternatives, and what each concession actually costs you
- Give/get - every concession gets something back; never concede unilaterally
- Anchoring - set the reference point early with total value, not just price
- Concession planning - plan your moves in advance: small, slowing, conditional
- Closing the gap - trial closes, summary of what's agreed, written confirmation

## The rule
Price is the last thing you negotiate. Everything else - terms, timeline, scope, support - moves first.
