# Objection Handling Guide

Real objections from 7+ years of selling, with the responses that actually worked - organized by type.

## Categories
- Price - "too expensive" / "we have a cheaper option"
- Timing - "not right now" / "maybe next quarter"
- Authority - "I need to run this up the chain"
- Status quo - "we're fine with what we have"
- Competition - "we're already talking to X"

## Format per objection
What they say -> what they mean -> response framework -> real example (anonymized)
