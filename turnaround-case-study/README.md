# Turnaround Case Study - 30% Improvement

A process turnaround written as a case study: baseline, diagnosis, fix, result, lesson.

## Structure
- Baseline: what was slow, how it was measured
- Diagnosis: where the bottleneck was and how the data revealed it
- Fix: what changed in the workflow, step by step
- Result: 30% turnaround reduction, validated by remeasurement
- Lesson: the systemic fix preventing recurrence
